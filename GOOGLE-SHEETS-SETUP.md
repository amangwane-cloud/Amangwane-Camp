# Amangwane Booking Workbook

Create one Google Sheets workbook called `Amangwane Bookings` with these tabs:

1. **Booking Register** - import `booking-register-template.csv`.
2. **Room Setup** - import `room-setup-template.csv`.
3. **Availability Board** - use `google-sheets-availability-setup.gs` to build the full-year date-row board.
4. **Dashboard** - to be generated by the production booking system.

Delete the `AMG-SAMPLE` row after importing the Booking Register.

## Full-year Availability Board

The preferred board has one date per row and Tent 1-10 as columns. It also marks 2026 South African public holidays and school-holiday periods in the `Holiday / School Holiday` column and shades those rows grey.

To build it in Google Sheets:

1. Open **Extensions > Apps Script** in the `Amangwane Bookings` workbook.
2. Delete the starter code and paste the contents of `google-sheets-availability-setup.gs`.
3. Save the project and run `buildAvailabilityBoard`.
4. Approve the Google Sheets permission prompt when asked.

The script creates or replaces the `Availability Board` tab. Staff can use `Available`, `Confirmed`, `Deposit pending` and `Maintenance` in the tent columns; the colours update automatically.

## Source of truth

The hosted booking database will be the source of truth. Google Sheets will be a staff-facing operational view. Direct bookings, staff bookings, deposit updates, cancellations and date changes will update the Booking Register and Availability Board automatically.

## Current confirmed rules

- Tents 1-8: Standard 2-bed, R900 per unit/night.
- Tent 9: 3-sleeper, R1,125 per unit/night.
- Tent 10: Family unit, R1,350 per unit/night.
- Single occupancy: only Standard 2-bed tents, R630 per night.
- Deposit: 50% within 48 hours of booking.
- Final payment: 30 days before arrival.
- Currency: ZAR.

## Connecting the website booking form (`booking.html`)

`booking.html` can write straight into this workbook through a Google Apps Script
Web App — no separate server needed.

### One-time setup

1. Open the `Amangwane Bookings` workbook > **Extensions > Apps Script**.
2. Add a new script file alongside `google-sheets-availability-setup.gs` and paste
   in the contents of `google-sheets-booking-backend.gs`.
3. Pick a long random string as the shared secret. Set `SHARED_SECRET` at the top
   of `google-sheets-booking-backend.gs` to that value.
4. **Deploy > New deployment**, type **Web app**:
   - *Execute as:* **Me**
   - *Who has access:* **Anyone**
   - Deploy, approve the permission prompt, and copy the `…/exec` URL.
5. In `booking.html`, edit the `CONFIG` block near the top of the `<script>`:
   - `backendUrl` = the `…/exec` URL from step 4
   - `secret` = the same string as `SHARED_SECRET`
6. After any later change to `google-sheets-booking-backend.gs`, run
   **Deploy > Manage deployments > (edit) > Version: New version**, or the live
   URL keeps serving the old code.

### What it does

- **On submit** (`doPost`): validates the request, checks every requested night on
  the **Availability Board** for that tent, sets those cells to `Deposit pending`,
  then appends a row to **Booking Register** with a fresh `AMG-#####` reference and
  the 50% deposit / balance worked out.
- **On load / date change** (`doGet?action=availability`): the form asks the backend
  which tent-nights are not `Available` and greys those tents out. If the call
  fails the form still submits; `doPost` re-checks and rejects a clash.

### Notes

- The shared secret sits in `booking.html` page source, so it only deters bots, not
  a determined person. Worst case is junk rows in the sheet (no payment is taken
  automatically) — delete them and staff carry on.
- `booking.html` and `admin.html` are gated behind `authenticated` in
  `staticwebapp.config.json`, carry `noindex`, and are not linked from any public
  page or the sitemap. To go live for guests: remove the `booking.html` line from
  `routes`, drop the `noindex` meta, and add the nav link + a sitemap entry.
- InnStyle has been removed from the site. Public "Book Now" CTAs now go to the
  contact form at `index.html#contact`; this page is the separate, gated flow.
